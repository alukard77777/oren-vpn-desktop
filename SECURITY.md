# Security policy

## Supported releases

Security fixes are assessed for the current release on the default branch and
the latest published stable Windows x64 release. Older releases may be
unsupported; users should update to the latest stable release before reporting
an issue.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub Security
Advisories for this repository. Do not open a public issue or include live
subscription URLs, credentials, private keys, or other sensitive material in a
public report.

Include the affected version or commit, Windows version, reproduction steps,
impact, and a minimal proof of concept where safe. Redact subscription URLs and
logs before attaching them.

The maintainers will acknowledge and assess reports as capacity allows. We do
not promise a response time, a fix, a disclosure date, or a bounty. Reports
that concern third-party components may need to be forwarded to their
maintainers.

## Scope

This policy covers the MultiCore source code, release packaging, updater,
desktop application, daemon, and elevated Windows core host in this repository.
It does not cover vulnerabilities in Xray-core, Mihomo, Windows, GitHub, or
other dependencies; report those to the relevant upstream project when
appropriate.
